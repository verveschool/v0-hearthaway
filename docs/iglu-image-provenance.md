# Iglu image provenance

HearthAway’s project owner confirmed the Iglu partnership and permission to use these property and room images in the catalogue. All downloaded files are hosted locally below `public/iglu/`; listing pages no longer depend on Iglu hotlinking or on the source CDN remaining unchanged. The source URL and local path for each captured image are recorded in [iglu-images.json](../app/accommodation/iglu-images.json) and [iglu-room-images.json](../app/accommodation/iglu-room-images.json).

On 13 November 2026, browser capture collected 221 official property-page images across 16 properties and 54 images across the seven Broadway room pages. The property pages include building exteriors, shared spaces, study areas, kitchens, gyms and room-category imagery where Iglu published them. Broadway room galleries include the visible room photographs; the standard studio floor plan is also hosted locally. Other room categories use their matching property-specific official room-card images. Mascot Duo is under development and its source gallery is illustrative; the listing description preserves that qualification.

JPEGs are stored as local files and were re-encoded at quality 82 where this reduced file size, with source dimensions retained up to 1600 pixels. PNG floor-plan and other PNG assets remain unchanged. No visitor-facing links point to Iglu or third-party source pages. The local metadata files are for provenance and internal data mapping only.

Original source assets are available at the URLs recorded in the JSON provenance manifests. Local copies improve delivery reliability and allow the existing HearthAway image pipeline/CDN to serve the files. They do not represent a live synchronization with Iglu; partner updates should refresh the captured assets and source metadata.
